# 《C++ OpenGL：从零到精通》教科书目录大纲

## 书籍定位

- **目标读者**：具备基础编程能力，希望系统掌握现代 OpenGL、实时渲染原理与图形程序工程实践的 C++ 学习者。
- **技术基线**：C++17、OpenGL 4.6 Core Profile、GLFW、GLAD、GLM、CMake。
- **主线成果**：读者将从创建首个窗口开始，逐步构建一个支持模型加载、PBR、阴影、后处理、延迟渲染与调试工具的可扩展实时渲染器。
- **贯穿案例**：每篇结束时将渲染器升级一个可运行版本；全书最后完成一个小型场景编辑与展示程序。

## 阅读与实践约定

### 前置知识与环境

1. C++ 基础：变量、函数、类、RAII、标准容器、智能指针。
2. 数学基础：向量、矩阵、三角函数、基础微积分与坐标系。
3. 工具链：Git、CMake、调试器、命令行与一款 C++ IDE。
4. 配套资源：示例代码、纹理与模型资源、每章练习、测试场景与性能基准场景。

### 每章固定结构

1. 学习目标与前置检查。
2. 概念讲解与图示。
3. 最小可运行示例。
4. 工程化改造与常见错误。
5. 本章检查清单、练习题与扩展挑战。
6. 渲染器里程碑与提交建议。
